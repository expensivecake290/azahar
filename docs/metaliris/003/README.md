# Phase 003

**Owner** `src/video_core/host_shaders/CMakeLists.txt`  
**Baseline** `c621eafbf316699c55f4c9c0c689d4e49498d360`

Native shaders are built individually with the configured SDK and
`-std=metal4.0`. The real compiler depfile tracks transitive includes. The
existing host_shaders target provides generated byte arrays at
`video_core/host_shaders/metal/<shader>.h`. The data agrees byte for byte
with the associated native Metal library. This packaging permits the renderer
to load host shaders independently of the frontend and its bundle layout.

The disposable fixture compiled, rebuilt deterministically, rebuilt after
an included file changed, rejected a broken include, and recovered.
An Objective-C++ program compiled and executed against the generated header.
The Metal-off configuration retained legacy shader graph entries. The native
configuration excluded the legacy graph entries. PICA200 passed all 48 cases
and 801 assertions.

Version 1 is the build rule and generated-header interface. Real asset
registration and native shader execution reopen as each owned MSL file
lands, starting with Phase 036. The test fixture lives only in scratch.
